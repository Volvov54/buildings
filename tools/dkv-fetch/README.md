# dkv-fetch

Автоматичне завантаження щомісячних Excel-звітів з порталу **ДКВ м. Києва**
(`dkv.kyivcity.gov.ua`) у `data/input/` — три файли, які читає застосунок Buildings:

| Сторінка порталу (розділ **не** «Звіти»!) | Файл |
|---|---|
| Майно (Об'єкти) → Об'єкти на Балансі — `/Balans/BalansObjects.aspx` | `Баланс.xlsx` |
| Оренда → Договори Оренди — `/Arenda/RentAgreements.aspx` | `Оренда.xlsx` |
| Оренда → Реєстр вільних приміщень — `/Reports1NF/Report1NFFreeSquare.aspx` | `ВільніПлощі.xlsx` |

> **Важливо про адреси.** Ті самі звіти є в розділі «Звіти» (з `?reportform=1`) — там
> вибір колонок живе один рендер і **не потрапляє в експорт**. Скрипт свідомо використовує
> нерепортові сторінки (розділи «Майно (Об'єкти)» / «Оренда»), де стан колонок зберігається.

## Що робить скрипт (повністю автоматично)

Для кожного звіту: вхід → відкриття сторінки → увімкнення «Дані ДПЗ» (якщо є) →
зняття залишкового фільтра → проставляння в «Додаткових Колонках» усіх колонок, які читає
програма, + «Вибрати» → «Зберегти у Файлі» → «XLS - Microsoft Excel» → перевірка
заголовків → перенесення у `data/input/`. Якщо колонки бракує — **старий файл не чіпається**.

## Встановлення (один раз)

```bash
cd tools/dkv-fetch
npm install
npx playwright install chromium
```

Потрібен також `python` у PATH (перевірка заголовків, лише stdlib).

## Запуск

```bash
npm run fetch                     # усі три звіти
npm run fetch -- --only=balans    # один: balans | orenda | freespace
```

Перший запуск — відкриється вікно браузера; **увійдіть у порталі вручну** (сесія
збережеться в `.chrome-profile/`, далі вхід не потрібен). Автологін: задати
`DKV_USERNAME` / `DKV_PASSWORD` у оточенні (форма `/Account/Login.aspx`).

## Колонки

Скрипт проставляє всі колонки зі списку `required` кожного звіту — це `*Index.header`
з `src/main/kotlin/com/vva/buildings/{Balans,Orenda,FreeSpace}Index.kt`. Уже позначені
пропускаються; відсутні в чеклисті (входять у постійні групи сітки) — логуються, це не
помилка. Порядок і зайві колонки значення не мають (`ColumnResolver` шукає за назвою).

## Планувальник завдань Windows

```
cmd /c "cd /d D:\proj\proj-kotlin-ai\buildings\tools\dkv-fetch && set DKV_USERNAME=... && set DKV_PASSWORD=... && npm run fetch"
```

(або тримати сесію в `.chrome-profile/` дійсною й без креденшалів).
